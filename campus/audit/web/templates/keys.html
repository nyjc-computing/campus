Audit API keys

Mint, re-scope, rotate and revoke the API keys that authenticate against campus.audit. A key is a bearer credential: whoever holds it can do everything its scopes allow, on every trace in this deployment. Mint one per person, with the narrowest scope that does the job and an expiry, and revoke it the moment the access is no longer needed — revocation is the only way to withdraw access a holder was given.
